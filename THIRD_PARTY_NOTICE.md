# Third-party code

`src/mska_backbone` contains code derived from the MSKA implementation by Mo
Guan, Yan Wang, Guangkun Ma, Jiarui Liu and Mingzu Sun:

- Repository: https://github.com/sutwangyan/MSKA
- Paper: *MSKA: Multi-stream keypoint attention network for sign language
  recognition and translation*, Pattern Recognition 165 (2025), 111602.

The metric files also retain their embedded upstream notices and citations.
No dataset, pretrained checkpoint or model weight is included in this
repository.
